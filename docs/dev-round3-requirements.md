# סבב 3 — עוד בקשות למפתח

בחרתי פריטים לפי אותו כלל שלמדנו מהסבבים הקודמים: **רק דברים שאין בהם פיתוי להמציא נתונים**. כל הפריטים כאן הם כלים/מנגנונים עצמאיים, לא "תראה לי סטטיסטיקה של X" — כי שם בדיוק קרו הבעיות (mock data, "עומס תקין" קבוע).

---

## 1. כלי "מנטימטר" בשיעור חי — ענן מילים + לוח מובילים
כבר יש בשיעור החי סקרים חיים עם תוצאות גרף. תוסיף:
- **ענן מילים (Word Cloud)**: המורה משגר שאלה פתוחה, תלמידים מקלידים מילה אחת כל אחד, והמילים מוצגות כענן ויזואלי על הלוח (מילים שחוזרות יותר — גדולות יותר). בלי ספריית חיצונית כבדה — CSS/SVG פשוט מספיק.
- **לוח מובילים (Leaderboard) לתחרות כיתתית**: חידון מהיר עם זמן קצוב לכל שאלה, ניקוד לפי מהירות תשובה נכונה, טבלת דירוג חיה שמתעדכנת.
- חשוב: תבנה את זה כרכיב עצמאי שמקבל props (רשימת שאלות, callback לשליחת תשובה) — **לא** עם נתוני תלמידים בדויים בקוד. אם צריך דוגמה להרצה, שיהיה קובץ נפרד וברור שהוא demo, לא מעורבב בלוגיקה.

## 2. הרצת קוד Java (בנוסף ל-Python שכבר קיים)
המשימות בPython כבר עובדות (Pyodide בדפדפן). Java דורש שרת ריצה — אין דרך להריץ Java בדפדפן. בקש:
- אינטגרציה עם שירות הרצת קוד חיצוני (Judge0 API הוא הפתרון הכי נפוץ ומתועד — יש גם גרסת self-host אם רוצים לא להיות תלויים בספק חיצוני).
- Endpoint אחד: מקבל קוד Java + קלט, מחזיר פלט/שגיאה. בלי UI מסובך — פשוט שיתחבר לאותו "הרץ קוד" שכבר יש בעורך.
- **אל תבנה "מדמה" הרצה** (למשל, לזהות תבניות בקוד ולהחזיר פלט מנוחש) — אם אין אינטגרציה אמיתית, עדיף שיחזיר הודעת "בקרוב" מאשר פלט מזויף.

## 3. מרכז עזרה אמיתי (Help Center)
כרגע יש רק דף FAQ בסיסי. באיפיון המקורי מתואר הרבה יותר:
- **כפתור עזרה צף** בפינת המסך שפותח תפריט מהיר בלי לצאת מהעמוד הנוכחי.
- **מדריכי "צעד אחר צעד"**: הדגשה ויזואלית (highlight) של כפתורים ספציפיים במסך עם חץ/טולטיפ, למשימות נפוצות כמו "איך מצדיקים חיסור".
- **שאלות נפוצות דינמיות**: רכיב FAQ עם חיפוש/סינון (התוכן עצמו — טקסט קבוע שאתה כותב, לא AI-generated).
- **טופס "דווח על באג"**: צילום מסך + תיאור, נשמר ברשימת פניות עם סטטוס (פתוח/בטיפול/נסגר).
- שוב: זה תוכן סטטי/מנגנון UI, לא דאטה של משתמשים אמיתיים — סיכון פיתוי נמוך.

## 4. נגישות (WCAG 2.1)
בלי שום נתונים מעורבים בכלל — טהור טכני:
- אפשרות הגדלת גופן גלובלית בלי לשבור את פריסת הכרטיסיות.
- בדיקת ניגודיות צבעים בכל הרכיבים, בדגש על Dark Mode.
- ניווט מלא במקלדת (Tab/Enter/Escape) בכל הדיאלוגים והתפריטים.
- תמיכה בקוראי מסך: `aria-label` נכונים על כל כפתורי אייקון (הרבה כפתורים באפליקציה הם רק אייקון בלי טקסט).
